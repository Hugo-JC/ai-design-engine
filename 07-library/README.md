# Biblioteca pessoal [BETA]

Opt-in via `ade.config.json` → `beta.library: true`. A biblioteca nunca é lida por defeito. Guarde media localmente; apenas notas próprias, manifestos e metadados devem ser versionados. Não automatize downloads de plataformas.

Coleções: `videos/`, `books/`, `mobbin/`. Pesquise por nicho, arquétipo e traços controlados (`scroll-scrub`, `scroll-pin`, `marquee`, `product-scale`, `type-display`, `color-by-variant`, `grid-visible`, `cursor-effect`, `page-transition`, `3d-product`, `editorial-index`). Preencha primeiro a nota em palavras próprias; padrões de referência não são moldes.

Imagens Mobbin só entram em `mobbin/` com `--source mobbin`. Livros guardam apenas princípios próprios; extração automática não está incluída.
